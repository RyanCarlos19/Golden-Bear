URSO DOURADO - VERSAO PARA APK

Conteudo:
  index.html      o aplicativo completo
  fonts/          pasta das fontes (veja fonts/LEIAME.txt)

Para gerar o APK:
  1. Coloque as 2 fontes na pasta fonts (veja fonts/LEIAME.txt).
  2. Use um conversor de site para APK (por exemplo Capacitor, Cordova ou um conversor online de HTML para APK)
     apontando para esta pasta, com index.html como pagina inicial.

Observacoes:
  - Funciona sem internet depois de instalado.
  - Os dados ficam guardados no proprio aparelho. Ao desinstalar o app ou limpar os dados, tudo e apagado.
  - Esta versao nao tem o chat de IA e comeca vazia, sem dados de exemplo.
